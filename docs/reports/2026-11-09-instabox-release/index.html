npm 公開だけ移せない理由

npm の trusted publishing は「GitHub が用意した実行環境」に限定されていて、自分の環境で動かす runner は対象外です。npm の公式文書に明記があります（2026-11-11 確認）。

移すには npm のトークンを新しく作って秘密として登録する必要があり、公開経路の守りが弱くなります。そのため公開だけ GitHub 側に残しました。

公開物

  • GitHub Release v0.32.2: harness-mcp-darwin-amd64、-darwin-arm64、-linux-amd64、-windows-amd64.exe。

途中で 1 回止まった

1 回目の公開処理は、公開の手前の試験 1 件で落ちました。同じ変更の PR では通っていた試験で、時刻に依存して揺らぐ種類です（1742ms）。

失敗した処理だけを再実行して成功しました。同じ揺らぎは再発し得ますので、リリース時にここで落ちたら、まず再実行を試すのが早道です。
